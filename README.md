# Sunrise Bread & Coffee Company

A fast-paced, **Potion Punch 2–inspired** browser cooking & counter-service game set in **Titusville, Florida** on the Space Coast.

## Features

- **Breakfast in a Cup Station**: Cook sausage and eggs on the griddle (don't let them burn!), scoop them into cups, ladle warm country gravy, and top with shredded cheddar or buttermilk biscuit crumbles.
- **Space Coast Coffee Bar**: Brew hot or iced coffees, mix Vanilla, Salted Caramel, Dark Mocha, and signature Babka Spice syrups, and finish with Cold Foam.
- **Hopkins Ave Bakery Oven**: Bake warm Cinnamon Rolls, Blueberry Muffins, Cheddar Bread Slices, and Buttery Croissants.
- **7-Day Shift Campaign & Endless Rush Mode**: Progressively unlock new menu items across 7 days with 1–3 star goals, or test your speed in Endless Rush (3 angry walk-outs ends the shift).
- **Space Coast Cast & Events**: Serve KSC Engineers, Beach Surfers, Morning Commuters, and Launch Tourists; shoo cheeky seagulls, wipe counter spills, and ride **2× Tip Rocket Launch Rush** waves!
- **Full Upgrade Shop & Synthesized Web Audio SFX**: Invest tips into extra griddle burners, faster boilers, burn-shield nonstick upgrades, heat-lamp warmers, and cozy decor—all saved in `localStorage`.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
